Plug-in Architecture

Modules are designed as plug-ins that can be turned on/off per agency. This allows:

  • Custom bundles: Each agency gets only the tools they need
  • One codebase: All modules share the same infrastructure
  • Easy scaling: New modules can be added without rewriting
  • Clear pricing: Agencies pay for what they use
