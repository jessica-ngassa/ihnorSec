Configuration Architecture

Rules are stored as configuration, not code. This allows:

  • Per-tenant customization: Each agency defines their own thresholds
  • Dynamic updates: Rules can be adjusted without redeployment
  • Sector optimization: Pre-configured presets for different use cases
  • No code changes: Same detection engine adapts to all configurations
